📊 Superstore Sales Dashboard (From Raw Data)

📌 Project Overview

This project showcases the complete transformation of raw, unstructured sales data into an interactive and insightful dashboard. 

The objective was to clean, process, and analyze the dataset to uncover meaningful business insights that can support data-driven decision-making.

Starting from raw data, all steps — including data cleaning, structuring, analysis, and visualization — were performed to create a comprehensive dashboard.

📷 Dashboard Preview - https://www.linkedin.com/feed/update/urn:li:activity:7429201975952478208/

🎯 Objectives

    •	To convert raw sales data into a structured and analysis-ready format 
    
    •	To identify key performance indicators (KPIs) such as sales, profit, and quantity 
    
    •	To analyze regional and category-wise performance
    
    •	To uncover trends and patterns in sales and profitability 
    
    •	To build a visually intuitive dashboard for stakeholders 
    

🛠️ Tools & Technologies Used

    •	Microsoft Excel 
    
    •	Data Cleaning 
    
    •	Data Transformation 
    
    •	Pivot Tables & Charts 
    
    •	Dashboard Design
    

🔄 Data Processing Workflow

1. Data Cleaning

    •	Removed duplicate records
   
    •	Handled missing and inconsistent values
   
    •	Standardized formats (dates, categories, etc.)
   
3. Data Transformation

    •	Created calculated columns for better analysis
   
    •	Structured raw data into a usable format
   
    •	Organized data into meaningful categories
   
5. Data Analysis

•	Performed KPI calculations such as: 

    •	Total Sales 
    
    •	Total Profit 
    
    •	Total Quantity
    
•	Analyzed performance across: 

    •	Regions 
    
    •	Categories & Sub-categories 
    
    •	Time periods 
    
7. Dashboard Creation

    •	Designed an interactive dashboard using Excel
   
    •	Used pivot tables, slicers, and charts
   
    •	Ensured clarity, readability, and usability
   

📈 Key Insights

    •	Identified top-performing regions contributing the highest revenue 
    
    •	Highlighted loss-making categories and sub-categories 
    
    •	Observed seasonal trends in sales performance 
    
    •	Analyzed customer purchasing behavior across different segments 
    

📊 Dashboard Features

    •	Interactive filters (Region, Category, Time Period) 
    
    •	KPI summary section for quick insights 
    
    •	Visual representations using charts and graphs 
    
    •	Clean and user-friendly layout
